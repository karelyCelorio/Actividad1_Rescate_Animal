# Sistema de Control de Rescate y Adopción — HTML5

Prototipo académico de tres páginas interconectadas, sin CSS y sin JavaScript.

- `index.html`: dashboard, bienvenida y resumen del refugio.
- `reportar.html`: formulario semántico HTML5 con título del caso, categorías, urgencia médica y descripción.
- `rescates.html`: tabla estructurada de casos ilustrativos.
- `assets/img/`: carpeta reservada para imágenes.

## Uso
Extraiga el ZIP y abra `index.html` en un navegador. La validación nativa del formulario no guarda registros ni añade casos a la tabla: no existe backend.
